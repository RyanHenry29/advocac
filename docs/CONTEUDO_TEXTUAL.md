#### Processos Administrativos
```
PROCESSOS ADMINISTRATIVOS

A Polícia Federal tem prazo para analisar
processos de CACs.

Mas muitas vezes esse prazo não é cumprido.

Quando isso acontece,
a via judicial é o caminho.

Já obtivemos liminares em diversos estados,
obrigando a PF a cumprir seus deveres legais.

Não espere o indeferimento.
Atue antes.
```

#### Polícia Federal
```
POLÍCIA FEDERAL

A PF é responsável pela regulação
de armas de fogo no Brasil.

Mas a burocracia nem sempre funciona.

Atrasos, indeferimentos indevidos,
sistemas fora do ar.

Quando a administração falha,
o Judiciário pode corrigir.

A gente sabe como fazer.
```
